# 老師回報維護模式

正式環境設定 `TEACHER_REPORT_MAINTENANCE=1`，重新部署後啟用。
恢復時改為 `0` 並重新部署；不需要修改、移除或回填資料庫資料。

啟用時：
- 老師回報頁顯示「回報功能暫停服務」及聯繫行政提示。
- 回報 API（GET、POST、PATCH）、照片新增／刪除、開課確認提交回傳 503 / REPORT_MAINTENANCE，且不進行資料寫入。
- LINE 的課後回報、課程進度、出席人數及舊式文字回報會回覆暫停訊息；不影響其他 LINE 操作或排程通知。
- 新發送的上課通知隱藏主教／助教回報按鍵與催促回報文案，保留課程資訊、導航及器材確認按鍵。單獨回報卡改為僅顯示課程資訊；回報催繳排程在維護期間跳過，上課提醒排程照常。
- LINE 已送達的歷史卡片無法由本次部署回溯更改；舊按鍵仍受回報 API 維護限制保護。
- 既有照片讀取、薪資查詢與管理端資料保留。未提交的新回報仍會影響原有計薪及車資判斷，需由行政核對。

不主動通知老師或園所；只有使用者開啟回報頁或嘗試回報時顯示提示。
